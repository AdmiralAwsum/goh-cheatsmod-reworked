About adding MOD infantry instructions: 1. Find human in this folder_ List. txt file and edit
2. According to/mp// Write one sentence per line for the format of infantry names (no need for spaces or summoning methods, be sure to include a path before the infantry name, please refer to lookme. jpg for details), and save after adding.
3. Finally, run import.exe to import. After re entering the game and loading a new campaign, summon in the ModTanks menu.

Instructions for adding MOD tanks: 1. Open the btr_list.txt, heavy_list.txt, light_list.txt, medium_list.txt file in the folder and edit it
2. Write one sentence per line according to the format of the tank model name's space summoning method, and save it after adding it.
3. Finally, run import.exe to import. After re entering the game and loading a new campaign, summon in the ModTanks menu.

The tank model name can be viewed in the editor; 
There are three summoning methods, and it is recommended to use method 1 for normal tank models; 
Recommended usage method 2 for tanks composed of multiple entity models; 
Only a very small number of special tank models use Method 3, such as robots that move fortress packs.
(Method 2 currently does not support multiplayer mode)
